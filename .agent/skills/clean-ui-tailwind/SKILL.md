# Clean UI Standards
1. Spacing & Tokens: Multiples of 4 (p-2, p-4, p-6). Consistent layout scales.
2. Interactive States: Always provide hover:, focus-visible:, and disabled: states.
3. Mobile First: Use responsive breakpoints (sm:, md:, lg:) and test overflow.
